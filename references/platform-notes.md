# Platform Notes — TikTok, Reels, Shorts, Meta

Same product, different platform, different ad. A hook and script that crush on TikTok can flop in
the Meta feed because the audience, the aspect ratio, the sound behavior, and the CTA mechanics
all differ. Match the platform the user names. Specs drift — treat exact numbers as guidance and
verify the current spec in the ad manager before a final shoot.

## The shared rules (true everywhere)

- **Vertical, full-screen: 9:16, 1080×1920.** The default for TikTok, Reels, Shorts, and Stories.
  (Meta feed also takes 4:5 / 1:1 — see below.)
- **Hook in the first 1-3 seconds**, as spoken words *and* on-screen text.
- **Design for mute.** Most feed views start silent. The ad must make sense with captions/text
  alone, then reward sound-on.
- **Captions on.** Burned-in or auto-captions lift completion across all four.
- **Safe zones.** Keep hook text and the CTA away from the edges — UI (username, buttons,
  caption) overlaps the bottom ~15% and right rail. Keep key text centered and clear of it.

## TikTok

- **Feel:** native, unpolished, creator-first. Ads that look like ads get scrolled. Lean UGC,
  raw, handheld, trend-aware.
- **Length:** 21-34s is a common sweet spot; the platform allows much longer, but retention rules.
- **Sound:** sound-on culture. Trending sounds and a real voice matter more here than anywhere.
- **Hook:** cold opens and pattern interrupts (Family 8) thrive. No intros.
- **CTA:** "link in bio," comment prompts, and the on-screen CTA sticker. Native phrasing wins.
- **Trends:** formats move fast — a trending transition or audio can carry an average script.

## Instagram Reels

- **Feel:** slightly more polished than TikTok but still native-first. Aesthetic matters more; raw
  still works.
- **Length:** 15-30s sweet spot.
- **Sound:** sound-on common, but many watch muted in-feed — captions essential.
- **Hook:** curiosity and desire (Families 1, 6) and a strong opening frame. Text hook in frame 1.
- **CTA:** "link in bio," profile link, or the promoted CTA button. Stories add link stickers.
- **Cross-post caveat:** don't post with a visible TikTok watermark — reach gets suppressed.

## YouTube Shorts

- **Feel:** value-forward and hook-driven; viewers arrive in a "show me" mindset.
- **Length:** up to 60s; 15-40s tends to hold best. Front-load value.
- **Sound:** frequently sound-on (headphones, lean-in viewing) — a clear VO carries well.
- **Hook:** state the payoff immediately — "here's how to [outcome] in [time]." Loop-friendly
  endings (that make the last second flow into the first) boost replays.
- **CTA:** verbal + on-screen; pinned comment link; channel/description link. Shorts CTAs are
  softer — a strong "watch this next" or subscribe-style nudge often outperforms a hard sell.

## Meta (Facebook + Instagram feed, Stories)

Meta is a placement family, not one format. The ad manager can auto-place one asset across feed,
Stories, Reels, and more — but the best-performing setups tailor per placement.

- **Feed aspect ratios:** **4:5 (1080×1350)** is the feed workhorse (most vertical real estate
  allowed in-feed); **1:1** also works. **Stories/Reels placements:** 9:16.
- **The text stack matters as much as the video.** A Meta ad has a **primary text** (the caption
  above the video — the first line is its own hook, and it truncates around ~125 characters
  before "...more"), a **headline** (below the video, short and benefit-led), and a **CTA button**
  (Shop Now, Learn More, Sign Up — pick the one that matches the action).
- **Hook:** works on two fronts — the first line of primary text *and* the first frame of the
  video. Write both.
- **Feel:** broader, often older audience than TikTok; slightly more explicit selling is tolerated.
  Proof and offer angles (Families 3, 7) pull well, especially in retargeting.
- **Static still works on Meta.** Unlike the video-only platforms, a single strong image with a
  sharp on-image hook and a tight caption is a legitimate, high-performing format here. See
  `/image-ad-prompt` and Family entries marked "Static."
- **CTA:** use the button + a direct line in the copy. "Tap Shop Now to start free" beats a vague
  "learn more."

## Quick reference

| | TikTok | Reels | Shorts | Meta feed |
|---|---|---|---|---|
| Aspect | 9:16 | 9:16 | 9:16 | 4:5 / 1:1 (Stories 9:16) |
| Sweet-spot length | 21-34s | 15-30s | 15-40s | 15-30s (video) |
| Sound | sound-on | mixed | often sound-on | mostly mute |
| Vibe | rawest | native-polished | value-first | broadest, sells harder |
| Static ads? | no | no | no | yes |
| CTA norm | link in bio | link in bio | pinned link | CTA button + copy |

When the user doesn't name a platform, ask, or write it for the most likely one and note that the
hook/CTA should shift for others.
