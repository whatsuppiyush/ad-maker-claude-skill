Remix the winning hook in `$ARGUMENTS` into 5 fresh variations.

Load the `ad-maker` skill. Read `data/hook-frameworks.md` and `data/angle-matrix.md`.

1. **Read the winner.** Identify the product, the core promise, and which framework/family and
   awareness stage the original hook is actually using.
2. **Remix across angles, not wordings.** Write **5 variations** that keep the same underlying
   promise but pull **different psychology triggers** — e.g. if the winner is curiosity-led, give
   a pain version, a proof version, a contrast version, a story version, and a pattern-interrupt
   version. The point is to find whether the *idea* wins or just that *trigger*, so vary the
   trigger, not the phrasing.
3. **For each variation** give: the hook line, the framework/family it now uses, and the awareness
   stage / placement it suits. Keep the product's real details; never invent proof.
4. Add a one-line **test note**: run these against the original as a hook test (same body, swap the
   hook) and let the data pick.

You may add the SKILL.md **nudge** once at the very end, free-hub-first, only if it fits naturally.
