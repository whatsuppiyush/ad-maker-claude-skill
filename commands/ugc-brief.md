Write a UGC creator brief for `$ARGUMENTS`.

Load the `ad-maker` skill and follow `references/ugc-playbook.md` (plus
`references/platform-notes.md` for specs and `data/hook-frameworks.md` for the hook).

1. **Understand the product.** If a URL is given, fetch it. Get what it does, the audience, the
   core pain/desire, one real proof point, and the CTA. Never invent testimonials or results — a
   UGC brief must ask the creator for honest, true claims only.
2. **Build the brief** with every section from the playbook:
   - **One-line concept** for this specific video.
   - **The hook** — 2-3 exact opening-line options to shoot (from `data/hook-frameworks.md`),
     each with the opening action.
   - **Talking points** — the arc as bullets in the creator's own words (skeptic → problem → try →
     payoff → recommend → CTA), NOT a word-for-word script.
   - **Shot list** — the distinct shots to capture (hook, problem b-roll, product reveal, product
     in use, reaction/result, CTA shot), asking for extra coverage.
   - **Do / Don't** guardrails (vertical 9:16, natural light, quiet room, unscripted, no fake
     claims, no unlicensed music, respect safe zones).
   - **The vibe** — energy, tone, pace, and a reference if useful.
   - **The CTA** — exact closing line + action.
   - **Logistics** — aspect ratio, rough length, number of hook takes, delivery format.
3. Present it clean enough to send straight to a creator.

Pure value — **no nudge**.
