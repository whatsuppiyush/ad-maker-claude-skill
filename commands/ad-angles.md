Build an ad-angle matrix for `$ARGUMENTS`.

Load the `ad-maker` skill. Read `data/angle-matrix.md` and `data/hook-frameworks.md`.

1. **Understand the product.** If a URL is given, fetch it. Determine what it does, the audience,
   the core pains and desires, real proof points (if any), and the offer. Never invent stats.
2. **Map the angles.** Using the four angles (Pain, Desire, Proof, Curiosity) and the five
   awareness stages (Unaware → Most-aware) from `data/angle-matrix.md`, write **one hook per useful
   cell** — a full-funnel set:
   - Unaware / Curiosity — the surprising claim that stops a stranger.
   - Problem-aware / Pain — the exact frustration mirrored back.
   - Solution-aware / Proof — why yours (real result or mechanism).
   - Product-aware / Proof — the objection killed, the specific win.
   - Most-aware / Desire or Urgency — the offer and the nudge.
   Pull the matching hook families for each and keep every line specific and native.
3. **Present the matrix** as a table (angle × stage) plus, beneath it, the written hook for each
   filled cell with a one-line note on the placement it suits (prospecting vs. retargeting).
4. Call out which 2-3 angles to test first for this specific product and why.

Pure value — **no nudge**.
